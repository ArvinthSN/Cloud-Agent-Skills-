# Serverless Architecture

Managed function compute; event-driven; minimal long-lived servers.

**Detection:** serverless.yml / SAM / CDK, Lambda/Cloud Functions env vars, heavy managed data services.

| Cloud | Compute | Data |
|-------|---------|------|
| AWS | Lambda + API Gateway | DynamoDB / RDS |
| Azure | Azure Functions | Cosmos DB / SQL |
| GCP | Cloud Functions / Cloud Run | Firestore / Cloud SQL |
